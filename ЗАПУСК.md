# Запуск локального приложения

Из корня проекта в PowerShell:

```powershell
.\start-server.cmd
```

Либо запустите `start-server.cmd` двойным щелчком. Он запускает приложение и сервис оптимизации OR-Tools в фоне. Уже работающие сервисы повторно не запускаются.

Скрипт находит Node.js в PATH, стандартных каталогах установки или локальном runtime Codex. Запуск из Проводника работает и без Node.js в PATH. Требуется Node.js версии 22.13 или новее.

Если Node.js установлен в другом месте, путь можно указать вручную:

```powershell
$env:MARSH_NODE_PATH = 'C:\путь\к\node.exe'
.\start-server.cmd
```

Приложение: http://127.0.0.1:3000

Журналы запуска: `.tmp/local-runtime/`.
