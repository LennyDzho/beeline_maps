# Исследование алгоритмов «Марш!»

Всё, что относится к выбору и сравнению алгоритмов, хранится внутри этой папки: наборы данных, подготовка, будущие эксперименты и результаты. Код, базы данных, конфигурация и демонстрационное наполнение MVP здесь не используются и не изменяются. Подключений к API или БД приложения нет.

Первый этап — дополнение датасета кейсодателя квалификациями исполнителей по историческим назначениям и точками старта по адресам офисов из исходных таблиц.

Сравнение десяти open-source решателей находится в [benchmark/](benchmark/README.md). Текущий статус и графики — в [промежуточном отчёте](benchmark/REPORT.md). Дорожная матрица OSM/OSRM зафиксирована; контрольные запуски выполняются. Спорные адресные привязки явно описаны в [адресной проверке](benchmark/reports/GEOCODING_REVIEW.md).

- [Описание данных и правил](datasets/beeline-v1/README.md).
- [Квалификации и точки старта всех исполнителей](datasets/beeline-v1/WORKERS.md).
- [Набор данных для программного использования](datasets/beeline-v1/dataset.json).
- [Проверки и сводные количества](datasets/beeline-v1/validation.json).

Актуальный набор для сравнения уточнён до квалификаций по конкретным HD внутри ВК: [бригады](datasets/beeline-hd-v2/WORKERS.md), [данные](datasets/beeline-hd-v2/dataset.json), [проверка](datasets/beeline-hd-v2/validation.json). Здесь 135 подтверждённых историей связей ВК/HD; у составной заявки требуются оба HD, но она остаётся одним визитом. Базовый набор v1 сохранён как исходный слой. Его результаты с широкими категориями хранятся [в отдельном архиве](benchmark/reports/archive-coarse-v1/README.md) и не смешиваются с новым сравнением.

Воспроизведение из корня проекта, Python 3.10+ без сторонних библиотек:

```powershell
python algorithm-research/scripts/build_dataset.py
python algorithm-research/scripts/build_dataset.py --check
```

Первая команда заново создаёт только три производных файла `dataset.json`, `WORKERS.md`, `validation.json` внутри `algorithm-research/datasets/beeline-v1`. Вторая выполняет те же проверки и сравнивает результат с сохранёнными файлами, ничего не записывая. Пути вычисляются относительно скрипта, поэтому рабочая директория не влияет на результат.
