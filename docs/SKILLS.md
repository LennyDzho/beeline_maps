# Навыки исполнителей

Настройка: **Администрирование → Навыки и допуски**, блок «Навыки». В том же разделе находится отдельный блок «Допуски и квалификации». Справочник хранится в существующей таблице `skills`, отдельно для каждого юрлица. Миграция и перенос данных не нужны. Управление требует права `admin.settings`.

Доступны добавление, переименование, описание и отключение неиспользуемых навыков. Связанный с исполнителем или любой версией типа работ навык нельзя отключить. Физического удаления нет; переименование не меняет ID и назначения. Названия не должны повторяться в пределах юрлица.

Типы работ передают `requiredSkillIds`, исполнители — `skillIds`. Устаревшие текстовые поля `requiredSkills` и `skill` поддерживаются для совместимости. При наличии ID название служит только для отображения. Обе формы и фильтр исполнителей используют данные справочника вместо зашитых списков.

У исполнителя можно выбрать несколько навыков. При сохранении существующих назначений сохраняются `level` и `confirmed_at`; удаляются только явно снятые навыки. Старый клиент с единственным полем `skill` не удаляет остальные назначения. Стартовое заполнение больше не возвращает снятые навыки у существующих демонстрационных исполнителей.

Проверки: `pnpm --dir apps/web test:skills`. Общие тесты справочников проверяют API, права, юрлица, переименование, отключение, выбор в формах, сохранение уровней и дат подтверждения. Тест перезапуска проверяет сохранность изменённых справочников и назначений. Все тесты работают в SQLite `:memory:`, не в рабочей базе.
