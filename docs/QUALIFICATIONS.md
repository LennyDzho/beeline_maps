# Допуски и квалификации

Веб-интерфейс: **Администрирование → Навыки и допуски**, блок «Допуски и квалификации». В том же разделе находится отдельный блок «Навыки».

Справочник хранится в существующей таблице `qualifications`, отдельно для каждого юрлица. Новая миграция не нужна. Управление требует права `admin.settings`. Добавление юрлиц по-прежнему остаётся административной операцией в базе.

Можно добавлять записи, менять название и описание, отключать и повторно включать неиспользуемые записи. Физического удаления нет. Если допуск связан с исполнителем или любой версией типа работ (включая архивную), отключение запрещено. Счётчик типов работ считает уникальные типы, а не версии.

Формы типов работ и исполнителей получают справочник с сервера. Связи передаются через `requiredQualificationIds` и `qualificationIds`; названия служат для отображения. Переименование не изменяет ID, код, политику срока действия, документы и существующие связи. Поле `validity_required` этим интерфейсом не редактируется.

У исполнителя можно выбрать несколько допусков. При сохранении сохраняются номера документов, даты и индивидуальные статусы оставленных допусков; удаляются только явно снятые назначения. Старые клиенты, передающие единственное название `clearance`, не удаляют остальные назначения. Существующий персональный статус допуска не заменяется флагом предупреждения из формы.

Стартовое заполнение не восстанавливает снятые назначения у уже существующих демонстрационных исполнителей и не перезаписывает переименованные или отключённые записи справочника. Это проверяет `tests/startup-seed.test.mjs`.

Отключённая запись недоступна для нового назначения. Уже существующая связь с отключённой записью может быть сохранена (для совместимости с ранее созданными данными). Планировщик по-прежнему проверяет активность и действительность допуска; настройка справочника не отменяет эти проверки.

Проверки: `pnpm --dir apps/web test:qualifications`. Тесты используют только SQLite `:memory:`: создание и переименование, изоляция юрлиц и прав, запрет отключения используемых записей, оба API назначения, сохранность документов и русские названия в формах.
