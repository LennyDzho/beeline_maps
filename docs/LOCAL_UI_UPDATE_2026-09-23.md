# Обновление локального интерфейса — 23 сентября 2026

Следующее уточнение владельца: [настройки приложения и расчёта сделаны глобальными](GLOBAL_SETTINGS_2026-09-23.md); общий источник установлен в OSRM / OpenStreetMap.

## Принятые уточнения и реализация

- Один общий справочник «Типы заявок»: ВК → HD. Порядок ВК: Подключение, Дозаказ, Локальная заявка, Глобальная проблема. Отдельные вкладки «Типы работ», «Навыки и допуски» и дублирующий раздел «Настройки ВК и оборудование» убраны.
- Рядом с выбранным ВК доступны «Редактировать ВК», «Оборудование ВК» и добавление HD. Добавление ВК открывается отдельной кнопкой.
- Окно оборудования ВК позволяет добавить существующую позицию, создать новую, изменить название/единицу/использование/количество и убрать связь с ВК. Удаление связи не удаляет оборудование из других ВК и из истории заявок. Изменение самой позиции справочника действует во всех связанных ВК.
- Состав оборудования ВК применяется один раз на выезд, включая несколько HD. Новая заявка сохраняет собственный снимок состава. Редактирование справочника не меняет существующие заявки и фактически выданные комплекты. Старый формат требований HD поддерживается для записей, у которых ещё не задан состав ВК.
- Компетенции исполнителя ВК–HD заменяют отдельные навыки, допуски и квалификации в карточках и при проверке назначения. Для назначения обязательны все выбранные HD в соответствующем ВК. Исторические записи старых справочников сохранены для совместимости.
- У исполнителя убраны участок и предупреждение об истечении допуска; список фильтруется по статусу, ВК и HD. Подразделение выбирается в шапке приложения.
- Табельные номера отображаются как обычные числа. Внутренние идентификаторы и ссылки сохранены. Новый номер выделяется в SQL при создании исполнителя.
- Госномер выбирается из автомобилей ресурсов своего подразделения: свободные исправные автомобили и уже закреплённый автомобиль. При смене автомобиля прежний освобождается. Проверка занятости и изменение исполнителя выполняются одной транзакцией, включая защиту от конкурирующего назначения. Убрано обязательное поле участка при создании ресурса.
- «Доступность для перепланирования» свёрнута под названием «Уточнить время и место освобождения». Это дополнительная оценка диспетчера для занятой бригады; работающий механизм сохранён.
